CASE Statement

SQL's way of implementing IF-THEN-ELSE logic. It allows you to create new columns based on conditions.

Basic Syntax

CASE WHEN x = 1 THEN 'a'
    WHEN x = 2 THEN 'b'
    ELSE 'c'
END AS new_column

Structure

• WHEN: The condition to test
• THEN: The value to return if condition is true
• ELSE: Default value if no conditions match
• END: Closes the CASE statement (always required!)

Question 1: Identifying Home Teams

Scenario: You need to identify matches in Germany that included FC Bayern Munich, FC Schalke 04, or other teams as the home team.

Team IDs:

  • FC Schalke 04: hometeam_id = 10189
  • FC Bayern Munich: hometeam_id = 9823
Show Solution
SELECT
    CASE WHEN hometeam_id = 10189 THEN 'FC Schalke 04'
        WHEN hometeam_id = 9823 THEN 'FC Bayern Munich'
        ELSE 'Other'
    END AS home_team,
    COUNT(id) AS total_matches
FROM matches_germany
GROUP BY home_team;

How it works: The CASE statement creates a new column called "home_team" that labels each match, then we COUNT how many matches each category has.

Question 2: Match Outcomes

Task: Create a CASE statement to identify matches as home wins, home losses, or ties.

Show Solution
SELECT
    date,
    -- Identify home wins, losses, or ties
    CASE WHEN home_goal > away_goal THEN 'Home win!'
        WHEN home_goal < away_goal THEN 'Home loss :('
        ELSE 'Tie'
    END AS outcome
FROM matches_spain;
Result: 100 out of 380 rows

Question 3: Barcelona Away Games

Task: Identify Barcelona's away games as wins, losses, or ties. Barcelona's awayteam_id = 8634.

Steps:

  1. LEFT JOIN teams_spain to get opponent names
  2. Use CASE to categorize outcomes from Barcelona's perspective
  3. Filter for only Barcelona's away games
Show Solution
-- Select matches where Barcelona was the away team
SELECT
    m.date,
    t.team_long_name AS opponent,
    CASE WHEN m.home_goal < m.away_goal THEN 'Barcelona win'
        WHEN m.home_goal > m.away_goal THEN 'Barcelona loss'
        ELSE 'Tie'
    END AS outcome
FROM matches_spain AS m
LEFT JOIN teams_spain AS t
    ON m.hometeam_id = t.team_api_id
WHERE m.awayteam_id = 8634;

Key Insight

When Barcelona is the AWAY team, they win when away_goal > home_goal (opposite of the home team logic!)
Result: 19 rows out of 19 rows

Complex CASE

Uses multiple conditions with AND/OR operators inside WHEN clauses to test complex logical scenarios.

Question: El Clásico Matches

Scenario: Barcelona vs Real Madrid - the most famous rivalry in soccer! Track these matches when Barcelona is the home team.

Team IDs:

  • Barcelona: 8634
  • Real Madrid: 8633
Show Solution
SELECT
    date,
    CASE WHEN hometeam_id = 8634 THEN 'FC Barcelona'
        ELSE 'Real Madrid CF'
    END AS home,
    CASE WHEN awayteam_id = 8634 THEN 'FC Barcelona'
        ELSE 'Real Madrid CF'
    END AS away,
    -- Identify possible home match outcomes
    CASE WHEN home_goal > away_goal AND hometeam_id = 8634 THEN 'Barcelona win!'
        WHEN home_goal < away_goal AND awayteam_id = 8633 THEN 'Real Madrid win!'
        ELSE 'Tie!'
    END AS outcome
FROM matches_spain
WHERE hometeam_id = 8634 AND awayteam_id = 8633;

Using AND in CASE

You can combine multiple conditions in a single WHEN clause using AND/OR operators for complex logic.

Question: CASE in WHERE Clause

Task: Generate a list of matches WON by Bologna (team_id = 9857). Use CASE inside the WHERE clause!

Show Solution
SELECT
    season,
    date,
    home_goal,
    away_goal
FROM matches_italy
WHERE
    CASE WHEN hometeam_id = '9857' AND home_goal > away_goal THEN 'Bologna win'
        WHEN awayteam_id = '9857' AND home_goal < away_goal THEN 'Bologna win'
    END IS NOT NULL;

How it works

• CASE returns 'Bologna win' when they win (home or away)
• CASE returns NULL when Bologna doesn't win
• IS NOT NULL filters out NULL values, keeping only wins!
Result: 27 rows (Bologna's victories!)

CASE + Aggregates

Combine CASE statements with COUNT, SUM, AVG to perform conditional aggregations - count or sum only when specific conditions are met.

How COUNT with CASE Works

Key Concept: CASE returns the value (like m.id) when the condition is TRUE, and NULL when FALSE. COUNT only counts non-NULL values!

    COUNT(CASE WHEN condition THEN m.id END)  -- Returns m.id if TRUE, NULL if FALSE
-- COUNT ignores NULLs, so only counts when condition is TRUE

Question: COUNT with CASE

Task: Count matches played in seasons 2012/2013 and 2013/2014 for each country.

Show Solution
SELECT
    c.name AS country,
    COUNT(CASE WHEN m.season = '2012/2013' THEN m.id END) AS matches_2012_2013,
    COUNT(CASE WHEN m.season = '2013/2014' THEN m.id END) AS matches_2013_2014
FROM country AS c
LEFT JOIN match AS m
    ON c.id = m.country_id
GROUP BY country;

Why this works

• For 2012/2013 matches: CASE returns m.id → gets counted
• For other seasons: CASE returns NULL → NOT counted
• Result: Separate count for each season in one query!
Result: 11 rows (one per country)

Question: SUM with CASE

Task: Calculate total home goals and away goals for team 8560, grouped by season.

Show Solution
SELECT season,
    SUM(CASE WHEN hometeam_id = 8560 THEN home_goal END) AS home_goals,
    SUM(CASE WHEN awayteam_id = 8560 THEN away_goal END) AS away_goals
FROM match
GROUP BY season;

Explanation: SUM only adds up the goals when the condition is met (when team 8560 is playing), otherwise adds NULL (which SUM ignores).

Result: 100 rows

Question: AVG with CASE - Calculate Tie Percentage

Task: Calculate the percentage of tied games in seasons 2013/2014 and 2014/2015 for each country.

Show Solution
SELECT
    c.name AS country,
    -- Calculate the percentage of tied games in each season
    AVG(CASE WHEN m.season='2013/2014' AND m.home_goal = m.away_goal THEN 1
        WHEN m.season='2013/2014' AND m.home_goal != m.away_goal THEN 0
        END) AS ties_2013_2014,
    AVG(CASE WHEN m.season='2014/2015' AND m.home_goal = m.away_goal THEN 1
        WHEN m.season='2014/2015' AND m.home_goal != m.away_goal THEN 0
        END) AS ties_2014_2015
FROM country AS c
LEFT JOIN match AS m
    ON c.id = m.country_id
GROUP BY country;

Clever Trick!

• Tied games get value 1
• Non-tied games get value 0
• AVG(1s and 0s) = percentage! (e.g., AVG of [1,0,1,0] = 0.5 = 50%)
Result: 11 rows

Simple Subquery

A query nested inside another query that can run independently. It's evaluated ONCE for the entire query.

Why Use Subqueries?

  • ✅ Comparing groups to summarized values (e.g., "above average")
  • ✅ Reshaping data
  • ✅ Combining data that cannot be joined

Question 1: High-Scoring Matches

Task: Find matches where total goals scored is MORE than 3× the average.

Show Solution
SELECT
    -- Select the date, home goals, and away goals scored
    date,
    home_goal,
    away_goal
FROM matches_2013_2014
-- Filter for matches where total goals exceeds 3x the average
WHERE (home_goal + away_goal) >
    (SELECT 3 * AVG(home_goal + away_goal)
     FROM matches_2013_2014);

Execution Order

  1. Subquery runs FIRST: Calculates 3 × average total goals
  2. Main query uses that single value to filter matches

Question 2: Teams That Never Played Home

Task: Find teams that NEVER played a game in their home city using NOT IN.

Show Solution
SELECT

Excludes any team_api_id that appears in the list of hometeam_ids. Perfect for finding "what's missing"!

Question 3: Teams with 8+ Home Goals

Task: Find teams that scored 8 or more goals in a single home match using IN.

Question 4: Subquery in FROM

Task: Count countries with matches that had 10+ total goals.

Key Rules for Subqueries in FROM

1. Must have an alias (e.g., AS sub)
2. Can join to other tables or subqueries
3. Behaves like a table
Show Solution
SELECT
    -- Select country name and the count match IDs
    name AS country_name,
    COUNT(sub.id) AS matches
FROM country AS c
-- Inner join the subquery onto country
INNER JOIN (SELECT id, country_id
            FROM match
            -- Filter the subquery by matches with 10+ goals
            WHERE (home_goal + away_goal) >= 10) AS sub
    ON c.id = sub.country_id
GROUP BY country_name;

Step-by-step

  1. Subquery creates a temporary table of high-scoring matches
  2. JOIN this to country table
  3. COUNT matches per country

Subquery in SELECT

Returns a SINGLE value that gets added as a new column to every row. Useful for comparing individual rows to aggregate values.

How It Works

SELECT
    Name,
    ListPrice,
    (SELECT AVG(ListPrice) FROM Product) AS AveragePrice
FROM Product;

Execution

  1. Subquery runs ONCE: calculates AVG(ListPrice) = single value (e.g., 2.67)
  2. This value is "broadcast" to every row in the result
  3. Each row gets the same overall average in a new column

Question 1: League vs Overall Average

Task: Compare average goals per league to the overall average across all leagues for 2013/2014.

Show Solution
SELECT
    l.name AS league,
    ROUND(AVG(m.home_goal + m.away_goal), 2) AS avg_goals,
    (SELECT ROUND(AVG(home_goal + away_goal), 2)
     FROM match
     WHERE season = '2013/2014') AS overall_avg
FROM league AS l
LEFT JOIN match AS m
    ON l.country_id = m.country_id
WHERE season = '2013/2014'
GROUP BY name;

Result: Each league gets its own average PLUS the same overall average for comparison.

Question 2: Calculate the Difference

Task: Add a column showing how much each league's average differs from the overall average.

Show Solution
SELECT
    name AS league,
    ROUND(AVG(m.home_goal + m.away_goal),2) AS avg_goals,
    -- Subtract the overall average from the league average
    ROUND(AVG(m.home_goal + m.away_goal) -
        (SELECT AVG(home_goal + away_goal)
         FROM match
         WHERE season = '2013/2014'),2) AS diff
FROM league AS l
LEFT JOIN match AS m
    ON l.country_id = m.country_id
WHERE season = '2013/2014'
GROUP BY l.name;

Interpretation

• Positive diff: League averages MORE goals than overall
• Negative diff: League averages FEWER goals than overall

Question 3: Subqueries Everywhere!

Task: Find stages where average goals > overall average. Use subqueries in SELECT, FROM, and WHERE!

Show Solution
SELECT
    stage,
    ROUND(s.avg_goals,2) AS avg_goal,
    (SELECT AVG(home_goal + away_goal)
     FROM match WHERE season = '2012/2013') AS overall_avg
FROM
    (SELECT
         stage,
         AVG(home_goal + away_goal) AS avg_goals
     FROM match
     WHERE season = '2012/2013'
     GROUP BY stage) AS s
WHERE
    s.avg_goals > (SELECT AVG(home_goal + away_goal)
                   FROM match WHERE season = '2012/2013');

Three Subqueries in One!

1. SELECT: Calculate overall average
2. FROM: Create temp table of stage averages
3. WHERE: Filter for stages above overall average

Correlated Subquery

References columns from the outer query. Cannot run independently. Re-evaluated for EVERY row in the outer query.

Performance

Correlated subqueries are SLOWER because they run once per row. Use only when necessary!

Simple Subquery

  • ✅ Runs ONCE
  • ✅ Independent
  • ✅ Returns same value for all rows
  • ✅ Faster

Correlated Subquery

  • ⚠️ Runs ONCE PER ROW
  • ⚠️ Depends on outer query
  • ⚠️ Different value per row
  • ⚠️ Slower

Classic Example: Salary Above Department Average

SELECT
    employee_name,
    salary,
    department_id
FROM employees e1
WHERE
    salary > (
        SELECT AVG(salary)
        FROM employees e2
        WHERE e1.department_id = e2.department_id);

How It Executes

  1. Outer query processes employee #1 (dept = Sales)
  2. Inner subquery runs: calculates AVG salary for Sales dept
  3. Compares employee #1's salary to Sales average
  4. Move to employee #2 (dept = IT)
  5. Inner subquery runs AGAIN: calculates AVG for IT dept
  6. ...repeats for EVERY employee

The Key

WHERE e1.department_id = e2.department_id creates the correlation - the subquery uses a value from the outer query!

Question: Highest Scoring Match per Country/Season

Task: Find the highest scoring match for EACH country in EACH season.

Show Solution
SELECT
    main.country_id,
    main.date,
    main.home_goal,
    main.away_goal
FROM match AS main
WHERE
    -- Filter for matches with the highest number of total goals scored
    (home_goal + away_goal) =
    (SELECT MAX(sub.home_goal + sub.away_goal)
     FROM match AS sub
     -- Join the main query to the subquery in WHERE
     WHERE main.country_id = sub.country_id
         AND main.season = sub.season);

Step-by-Step Execution

  1. Row 1: England, 2014 season → Subquery finds MAX goals for England 2014
  2. Row 2: France, 2015 season → Subquery finds MAX goals for France 2015
  3. Row 3: England, 2014 season → Subquery finds MAX goals for England 2014 (same as row 1)
  4. Process continues for every row...

Why Correlated?

• We need the MAX for EACH country-season combination
• A simple subquery would give us the MAX across ALL matches
• Correlation allows us to filter the MAX by current row's country and season

Why NOT a Simple Subquery?

WHERE (home_goal + away_goal) = (SELECT MAX(home_goal + away_goal) FROM match)
This would only find the ONE match with the absolute highest score across all countries/seasons!

Nested Subquery

A subquery inside another subquery. Useful for breaking complex operations into smaller, manageable steps.

Question 1: Max Goals vs Premier League

Task: Compare max goals per season across all leagues to the max for England Premier League.

Show Solution
SELECT
    season,
    MAX(home_goal + away_goal) AS max_goals,
    (SELECT MAX(home_goal + away_goal)
     FROM match
     WHERE season = main.season
         -- Nested subquery to get country_id for Premier League
         AND country_id IN (SELECT country_id
                            FROM League
                            WHERE name='England Premier League')
    ) AS pl_max_goals
FROM match AS main
GROUP BY season;

Execution Order (Inside Out)

  1. Innermost: SELECT country_id FROM League WHERE name='England Premier League'
  2. Middle: Use that country_id to filter matches
  3. Outer: Compare overall max to Premier League max

Question 2: Multi-Level Nesting

Task: What's the average number of matches per season where a team scored 5+ goals? Build this in 3 steps!

Building Block Approach

Step 1: Find matches with 5+ goals
Step 2: Count these matches per country/season
Step 3: Average these counts by country
Show Solution

Step 1: Find Matches with 5+ Goals

SELECT
    country_id,
    season,
    id
FROM match
WHERE home_goal >=5 OR away_goal >=5;

Step 2: Count Matches per Country/Season

SELECT
    country_id,
    season,
    COUNT(id) AS matches
FROM (
    SELECT
        country_id,
        season,
        id
    FROM match
    WHERE home_goal >= 5 OR away_goal >= 5)
    AS subquery
GROUP BY country_id, season;

Step 3: Average by Country

SELECT
    c.name AS country,
    -- Calculate the average matches per season
    AVG(outer_s.matches) AS avg_seasonal_high_scores
FROM country AS c
-- Left join outer_s to country
LEFT JOIN (
    SELECT country_id, season,
        COUNT(id) AS matches
    FROM (  -- INNER SUBQUERY
        SELECT country_id, season, id
        FROM match
        WHERE home_goal >= 5 OR away_goal >= 5) AS inner_s
    -- Close parentheses and alias the subquery
    GROUP BY country_id, season) AS outer_s
    ON c.id = outer_s.country_id
GROUP BY country;

Pro Tip

When writing nested subqueries:
1. Start with the innermost query
2. Test it independently
3. Wrap it in the next level
4. Test again
5. Continue building outward

What We Built

Inner subquery (inner_s): Filters high-scoring matches
Outer subquery (outer_s): Counts matches per country/season
Main query: Joins to country table and averages
