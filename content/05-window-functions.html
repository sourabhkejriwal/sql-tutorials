Problem: Can't Mix Aggregate and Non-Aggregate Data

When you use GROUP BY, you collapse rows. You can't see individual match details alongside aggregate statistics.

Example: GROUP BY Limitation

Question: Show each team's average goals scored.

SELECT
    team,
    AVG(goals_scored) AS avg_goals
FROM matches
GROUP BY team;

Output

teamavg_goals
Arsenal2.50
Liverpool1.33
Chelsea3.00

Problem

We lost all the individual match details! We can only see aggregated data.
We can't answer: "Show each match with its goals AND how it compares to the team's average"

Solution: Window Functions!

Window functions let you keep ALL rows while adding aggregate calculations!

Same Question with Window Functions

Question: Show each match with goals scored AND team's average.

SELECT
    match_id,
    team,
    goals_scored,
    AVG(goals_scored) OVER(PARTITION BY team) AS team_avg
FROM matches;

Output - All Rows Preserved!

match_idteamgoals_scoredteam_avg
1Arsenal32.50
2Arsenal22.50
3Arsenal12.50
4Arsenal42.50
5Liverpool21.33
6Liverpool11.33
7Chelsea33.00

Notice

All 7 rows are kept! Each row shows individual match data PLUS the team's average.

OVER()

Defines the "window" (set of rows) for the calculation. An empty OVER() means "all rows in the result."

Example 1: Overall Average Goals

Question: Show each match with overall average goals scored across ALL matches.

SELECT
    match_id,
    team,
    goals_scored,
    AVG(goals_scored) OVER() AS overall_avg
FROM matches
WHERE season = '2023/24'
ORDER BY match_id;

Step 1: Data Without Window Function

match_idteamgoals_scored
1Arsenal3
2Arsenal2
3Arsenal1
4Arsenal4
5Liverpool2
6Liverpool1
7Chelsea3
↓

Step 2: Calculate AVG(3,2,1,4,2,1,3) = 2.29

Window = ALL 7 rows
AVG(goals_scored) = (3+2+1+4+2+1+3) / 7 = 2.29
↓

Step 3: Add that value to EVERY row

match_idteamgoals_scoredoverall_avg
1Arsenal32.29
2Arsenal22.29
3Arsenal12.29
4Arsenal42.29
5Liverpool22.29
6Liverpool12.29
7Chelsea32.29

Key Insight

The overall_avg is the SAME for every row because OVER() includes all rows in the calculation.

RANK()

Assigns a ranking number to each row based on ORDER BY. Equal values get the same rank, with gaps.

Example 1: Rank Matches by Goals Scored

SELECT
    match_id,
    team,
    goals_scored,
    RANK() OVER(ORDER BY goals_scored DESC) AS goal_rank
FROM matches
WHERE season = '2023/24';

PARTITION BY

Divides rows into groups and performs the window function separately on each group. Unlike GROUP BY, it doesn't collapse rows!

Sliding Window

A moving frame of rows for calculating running totals, moving averages, etc.

Syntax: ROWS BETWEEN

FUNCTION() OVER(
    ORDER BY column
    ROWS BETWEEN <start> AND <end>
)

Keywords:

  • UNBOUNDED PRECEDING - From the very first row
  • CURRENT ROW - Up to the current row
  • N PRECEDING - N rows before current
  • N FOLLOWING - N rows after current

Example 1: Running Total of Arsenal Goals

Question: Show Arsenal's cumulative goals through the season.

SELECT
    match_id,
    match_date,
    goals_scored,
    SUM(goals_scored) OVER(
        ORDER BY match_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_total
FROM matches
WHERE team = 'Arsenal' AND season = '2023/24'
ORDER BY match_date;

Step-by-Step Execution

match_idmatch_dategoals_scoredWindowrunning_total
12023-08-153SUM(3)3
22023-08-222SUM(3, 2)5
32023-08-291SUM(3, 2, 1)6
42023-09-054SUM(3, 2, 1, 4)10

How It Works

• Match 1: Window = [3] → Total = 3
• Match 2: Window = [3, 2] → Total = 5
• Match 3: Window = [3, 2, 1] → Total = 6
• Match 4: Window = [3, 2, 1, 4] → Total = 10

Example 2: 3-Match Moving Average

Question: Calculate Arsenal's average goals over the last 3 matches.

SELECT
    match_id,
    match_date,
    goals_scored,
    AVG(goals_scored) OVER(
        ORDER BY match_date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS moving_avg_3
FROM matches
WHERE team = 'Arsenal' AND season = '2023/24'
ORDER BY match_date;

Visual Explanation - The Window "Slides"

match_idmatch_dategoals_scoredWindow (last 3)moving_avg_3
12023-08-153AVG(3)3.00
22023-08-222AVG(3, 2)2.50
32023-08-291AVG(3, 2, 1)2.00
42023-09-054AVG(2, 1, 4) ← Window slides!2.33

The "Sliding" Part

• Rows 1-3: Window is smaller (not enough previous rows)
• Row 4: Window = [row 2, row 3, row 4] - it SLIDES!
• The window always looks at current + 2 preceding rows

Example 2: Rank + Partition Combined

Question: For each team, find their top 2 scoring matches.

WITH ranked_matches AS (
    SELECT
        match_id,
        team,
        opponent,
        goals_scored,
        RANK() OVER(
            PARTITION BY team
            ORDER BY goals_scored DESC
        ) AS rank_in_team
    FROM matches
    WHERE season = '2023/24'
)
SELECT *
FROM ranked_matches
WHERE rank_in_team <= 2
ORDER BY team, rank_in_team;

Example 3: Compare Current vs Previous Match

Question: Show goals scored in current match vs previous match.

SELECT
    match_id,
    match_date,
    team,
    goals_scored,
    LAG(goals_scored) OVER(
        PARTITION BY team
        ORDER BY match_date
    ) AS previous_match_goals,
    goals_scored - LAG(goals_scored) OVER(
        PARTITION BY team
        ORDER BY match_date
    ) AS change
FROM matches
WHERE team = 'Arsenal' AND season = '2023/24'
ORDER BY match_date;

Output

LAG() Function

Gets the value from the PREVIOUS row. Perfect for comparing trends!

Example 4: Complete Performance Dashboard

Question: Create a comprehensive view with multiple window functions.

SELECT
    match_id,
    match_date,
    team,
    goals_scored,
    -- Team statistics
    AVG(goals_scored) OVER(PARTITION BY team) AS team_avg,
    RANK() OVER(PARTITION BY team ORDER BY goals_scored DESC) AS rank_in_team,
    -- Running statistics
    SUM(goals_scored) OVER(
        PARTITION BY team
        ORDER BY match_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_total
FROM matches
WHERE team = 'Arsenal' AND season = '2023/24'
ORDER BY match_date;
